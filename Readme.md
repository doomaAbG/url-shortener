# 🔗 URL Shortener Microservice

Высокопроизводительный REST API микросервис для сокращения ссылок, написанный на Go с использованием принципов Clean Architecture.

🛠 Технологический стек

* **Бэкенд:** Go (роутер `chi` для HTTP REST API, структурированное JSON-логирование `slog`)
* **База данных:** PostgreSQL 16 (драйвер `pgxpool` для управления пулом соединений)
* **Миграции:** `golang-migrate` (автоматический контроль схемы БД при старте)
* **Инфраструктура:** Docker / Docker Compose

🏗 Архитектура системы

1. Клиент отправляет HTTP POST-запрос на создание короткой ссылки (`/shorten`).
2. Роутер `chi` пропускает запрос через стэк Middleware (`RequestID`, `RealIP`, `Logger`, `Recoverer`) и передаёт его в `URLHandler`.
3. `URLHandler` валидирует JSON-запрос и вызывает уровень бизнес-логики `URLService`.
4. `URLService` генерирует 6-значный алиас через криптографический генератор `crypto/rand` и задействует абстракцию `URLRepository`.
5. `PostgresRepo` выполняет `INSERT`-запрос в PostgreSQL с возвратом `ID`.
6. При GET-запросе (`/{alias}`) сервис мгновенно ищет запись и возвращает HTTP 302-редирект на целевой ресурс.

🚀 Запуск и проверка

1. Требования
Установите Go (версии 1.22+) и Docker Compose.

2. Запуск окружения и сервиса
 Поднимите контейнер с базой данных PostgreSQL:
 docker compose up -d

 Запустите веб-сервер (миграции накатываются автоматически при старте):
 go run ./cmd/api
